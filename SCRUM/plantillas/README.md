# Plantillas reutilizables

Copiar dentro de la carpeta del sprint y completar con evidencia real. Un campo vacío no es aprobación; una plantilla no inicia trabajo.

- [Historia](HISTORIA.md): formato específico y revisión INVEST.
- [Bitácora](BITACORA.md): progreso no bloqueante y handoff de sesión.
- [Bloqueo](BLOQUEO.md): impedimento y alternativas.
- [Cambio](CAMBIO.md): delta y autorización antes de ampliar alcance.
- [Evidencia](EVIDENCIA.md): prueba por criterio y versión.
- [Revisión y retrospectiva](REVISION.md): aceptación, carryover y mejoras.

Para nuevos sprints reutilizar la estructura de [SP-001](../sprints/SP-001/ARRANQUE.md) con nuevo ID, versión y aprobación vacía. El backlog maestro conserva el mismo ID de historia aunque ésta cambie de sprint.
