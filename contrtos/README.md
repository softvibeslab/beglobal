## 🚀 Cómo Usar

### Paso 1: Preparar el Documento
Abrir `NDA-BeGlobal-Proveedor.docx` en Word/Google Docs y completar:

```
[***] = Campos a rellenar:
- Nombre de la otra Parte
- Domicilio del proveedor
- Contacto/Representante
- Email
- Teléfono
- Fecha de firma
- Domicilio BeGlobal (opcional)
- Representante BeGlobal
```

### Paso 2: Personalizar
- Revisar jurisdicción: **Ciudad de México** (puede cambiar si aplica)
- Revisar contactos de BeGlobal (completar datos)
- Validar períodos: 5 años confidencialidad, 3 años vigencia

### Paso 3: Revisar con Abogado
Antes de usar operacionalmente, hacer que un asesor legal revise:
- Cláusulas específicas del negocio
- Excepciones adicionales si aplica
- Adaptaciones jurisdiccionales

### Paso 4: Firmar
- Ambas partes firman en las líneas designadas
- Guardar copia firmada en archivo legal
- Archivar en expediente del cliente/proveedor

## 📋 Casos de Uso

✅ **Válido para**:
- Solicitudes de información (RFI)
- Solicitudes de propuestas (RFP)
- Evaluación de proveedores
- Intercambio de especificaciones técnicas
- Compartir roadmap/arquitectura
- Concepto de solución (POC)

❌ **NO válido para**:
- Contratos de servicios (necesita Statement of Work)
- Relaciones de empleo (necesita NDA de empleado)
- Licencias de software (necesita licencia específica)
- Acuerdos de asociación (necesita partnership agreement)

---

## 🔒 Protecciones Clave

### Duración
- **Confidencialidad**: 5 años post-revelación
- **Vigencia total**: 3 años + 30 días de notificación para terminar

### Cobertura
- Código fuente y arquitecturas
- APIs y frameworks propietarios
- Datos y bases de datos
- Información financiera
- Contactos de clientes
- Planes estratégicos

### Excepciones a Confidencialidad
1. Información pública
2. Conocimiento previo
3. Recibida de terceros legítimamente
4. Desarrollo independiente
