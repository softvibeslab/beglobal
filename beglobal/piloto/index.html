Cómo funciona

El equipo puede presentar este flujo como la versión simple antes de abrir el dashboard detallado.

Responsabilidades

Quién hace qué

Separa autoridad de operación para no mezclar permisos ni promesas.

Corporate

Gobierna la cancha.

  • Aprueba método, límites y cambios sensibles.
  • Define qué se puede prometer y qué se escala.
  • Cuida permisos, calidad y decisiones críticas.

Team

Prueba y opera.

  • Valida casos reales y checklist.
  • Documenta errores, soporte y evidencia.
  • Convierte feedback en tareas accionables.

Member

Ejecuta una misión.

  • Recibe diagnóstico simple.
  • Completa una acción por vez.
  • Entrega evidencia para medir avance.

Activar el sandbox y simular una conversación con misión + evidencia.

Paso 4

Decidir siguiente acción

Registrar ajustes, dueños y evidencia esperada para Go / Adjust / Stop.
