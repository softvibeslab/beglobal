# /vapiold — sitio Be Global, chat escrito Hermes y voz Vapi

Página estática. El iframe contiene `https://www.beglobalpro.org/`. El chat de texto abre el mismo asesor que `/vapi/` (`https://chatbeglobal.softvibes.pro/asistente/`). El widget Vapi queda en modo `voice`.

Publicar `index.html`, `styles.css`, `app.js`, `config.json`, `logo-beglobal.png` y `SHA256SUMS` en `public_html/vapiold/`. No modificar `/vapi/`.

Al terminar un diagnóstico iniciado aquí, el panel muestra el cierre de acompañamiento con Ver membresías y la opción de preguntar por un webinar.
