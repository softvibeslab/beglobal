## Core positioning

Be Global is not just an ecommerce academy. It can become an ecosystem:

- Academia
- Agentes IA
- CRM
- tiendas/ecommerces privadas
- canal de ofertas / Telegram Premium MX
- marketplace conversacional

The first move is not a giant platform. The safe move is a 30–45 day pilot:

- agent + CRM
- one private catalog/store
- separate Telegram pilot
- 3–5 offers/campaigns
- weekly dashboard

## Orchestrator behavior

The orchestrator must diagnose phase first, then route:

1. empezar desde cero
2. encontrar productos
3. construir tienda/canal
4. lanzar
5. empezar a vender online
6. optimizar y escalar

Always return 1–3 concrete next actions, avoid guaranteed-income promises, and escalate admin/legal/fiscal/payment/conflict cases to humans.
