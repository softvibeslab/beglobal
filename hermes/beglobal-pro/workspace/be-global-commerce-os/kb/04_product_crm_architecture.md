# 04 — Arquitectura Producto + CRM

## Mapa del sistema
Instagram/contenido atrae atención. El agente de diagnóstico convierte esa atención en perfil estructurado. El CRM clasifica y recomienda siguiente paso. La academia activa. El catálogo, tiendas privadas y Telegram convierten aprendizaje en acción comercial. Reporting cierra el loop.

## Pipelines
### Audience → Academy
Nuevo lead → diagnóstico iniciado → diagnóstico completo → calificado → oferta presentada → compra/inscripción → activado → upsell → advocate.

### Private Store Launch
Interés → diagnóstico tienda → plan aprobado → catálogo asignado → tienda configurada → QA → lanzamiento → primera venta → optimización.

### Affiliate / Offer Monetization
Interés afiliado → aprobado → link generado → primeros clics → primera conversión → promotor activo → payout/reconocimiento → reactivación.

## Principio de integración
Empezar con pocas conexiones confiables:
- lead capture → CRM,
- diagnóstico → CRM,
- pago/inscripción → permisos,
- CRM tier → bot Telegram piloto,
- catálogo/links → tracking,
- dashboard semanal.
