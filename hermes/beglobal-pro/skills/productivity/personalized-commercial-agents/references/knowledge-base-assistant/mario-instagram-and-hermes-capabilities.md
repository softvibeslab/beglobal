# Mario persona: Instagram radar + full Hermes capability

Session-derived guidance for Mario Villanueva / BEAT persona work.

## User correction captured

The user clarified two workflow preferences:

1. Instagram should be used as a **radar de contexto** for Mario — not as the primary source of truth, but to see what Mario is currently posting, signaling, promoting, or focused on before drafting strategy/content/sales recommendations.
2. The assistant should not limit itself to the narrow “Mario agent” capability set. It should use **all relevant Hermes tools, skills, agents, browser, files, research, and delegation** when useful, while keeping Mario’s KB, BEAT, and voice as the strategic frame.

## Practical pattern

For Mario sales/content/brand/proposal tasks:

1. Start with the local Mario KB: AGENTS.md, tone, services, brand, processes, objections/FAQs when relevant.
2. If current context matters, inspect Mario’s Instagram/public presence as latest-context intake:
   - bio/title/CTA
   - visible positioning
   - recent themes/posts when accessible
   - collaborators/ecosystem signals
   - current offers/events/keywords
3. For external prospect/collaboration work, inspect the prospect’s public profile too.
4. Synthesize using this structure:
   - KB-grounded Mario angle
   - current public signal/context
   - opportunity or fit
   - concrete output: message, follow-up, proposal, content plan, or next step
5. Use other Hermes skills/tools freely when they improve the work: docs, research, browser, delegation, scheduling, media generation, etc.

## Tone

Keep Telegram/user-facing drafts short, casual, and iterative unless the user asks for a full document.

Preferred phrasing:

- “potencia completa de Hermes, criterio de Mario”
- “Instagram como radar, no como fuente principal”
- “menos teoría, más aterrizado al momento real de Mario”

## Pitfalls

- Do not answer Mario strategy purely from generic marketing theory.
- Do not treat Instagram as approved KB facts; label public signals as current/visible context.
- Do not overconstrain yourself to only Mario KB capabilities when tools/skills can improve execution.
- Do not invent results, prices, dates, testimonials, or official partnerships from social bios alone.
