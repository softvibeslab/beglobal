# Founder pricing and simplified tiers for personalized AI agents

Use this when Chris/Roger want a simpler first-customer offer. Keep the offer easy to understand; avoid too many tiers early.

## Recommended simplified ladder

### 1. Agente Personal

**Beta/founder price:** `$197 setup + $29/mes`  
**Future normal price:** `$497 setup + $97/mes`

**Positioning:** "Piensa contigo."  
**Promise:** An agent that understands the client's business, voice, offer, and ideas so they stop starting from zero with generic ChatGPT.

**Includes:**
- business/person context
- tone of voice
- offer/services
- basic FAQs
- content ideas
- message/email/post drafting
- idea organization
- basic memory/context updates
- 1 monthly update

**Explicitly excludes:**
- MCPs
- APIs
- CLI tools
- automations
- external tool integrations
- calendar/CRM/docs/payments access

Commercial wording:
> "En el plan Personal el agente ya viene entrenado con tu negocio, pero no está conectado a tus herramientas. Si quieres que actúe dentro de calendario, CRM, documentos o sistemas externos, eso entra como Súper Poder."

### 2. Agente Comercial

**Beta/founder price:** `$347 setup + $59/mes`  
**Future normal price:** `$997 setup + $197/mes`

**Positioning:** "Vende contigo."  
**Promise:** An agent trained to help answer leads, handle objections, write follow-ups, and create simple proposals.

**Includes everything in Personal, plus:**
- sales scripts
- objection handling
- follow-ups
- closing messages
- simple proposals
- lead conversation analysis
- 2 monthly updates

### 3. Agente con Súper Poderes

**Beta/founder price:** `$797 setup + $149/mes`  
**Future normal price:** from `$2,500 setup + $500/mes`

**Positioning:** "Ejecuta contigo."  
**Promise:** The agent not only thinks/responds; it connects to tools and executes a basic workflow.

**Includes everything in Comercial, plus:**
- 1 simple súper poder included
- one external tool connection or basic workflow
- implementation support
- monthly optimization

Examples of first simple súper poderes:
- Google Docs/Drive
- Google Calendar
- Airtable
- Notion
- Telegram
- simple dashboard

## Founder program conditions

Frame these as limited founder/beta prices, not discounts. For the first 5 clients, ask for:
- testimonial or private reference
- permission to use anonymized case study
- weekly feedback during the first 30 days
- minimum 2 months of subscription

## Key sales distinction

- **Tier 1:** thinks and responds; no integrations.
- **Tier 2:** helps sell; still no integrations by default.
- **Tier 3:** connects and executes via one included súper poder.

Do not blur Tier 1 and Tier 2: Tier 1 saves time; Tier 2 is trained around revenue and lead conversion.
