# Mario Softvibes / Chris Commercial Channel Onboarding

Use this reference when preparing a Telegram/WhatsApp group to receive Mario or another collaborator into the commercial channel.

## Core framing

The group is not casual chat and not primarily Mario brand strategy. It is the **Chris commercial channel** for selling and building personalized AI agents.

Primary work:

- prospects
- sales messages
- objections
- demos
- proposals
- follow-ups
- use cases
- packages/offers
- converting client info into ready-to-configure agents

Mario/BEAT voice is a style layer: human, clear, grounded, low-pressure, commercially intelligent. Do not let the conversation drift into Mario’s broader ecosystem unless explicitly asked.

## How Mario should use the agent

```text
Mario, cuando quieras usar al agente, háblale directo con contexto.

Ejemplos:

1. “Tengo este lead: [link]. Ayúdame a venderle un agente personalizado.”
2. “Me dijo que está caro. Dame una respuesta humana, clara y sin presión.”
3. “Hazme una demo para este cliente con 3 casos de uso.”
4. “Te paso la info de un cliente. Hazme el agente listo para agregarlo a su grupo.”
5. “Hazme follow-up para alguien que no contestó.”

Mientras más contexto le des, mejor responde.
```

## First live test

Use a real lead immediately. Example:

```text
Tengo este lead: [Instagram o negocio]. Ayúdame a venderle un agente personalizado.
```

Expected output:

- angle of sale
- likely pains
- 3–5 use cases
- initial message
- CTA for personalized demo
- follow-up

## Group operating rule

Everything posted should turn into commercial action:

- lead → message
- objection → response
- client → proposal
- client info → configured agent package
- idea → offer/demo/content
- conversation → next steps
