# Chris → Mario workflow transfer

Use when Roger/Chris asks to analyze the Mario/Softvibes group context so Chris can teach Mario the commercial workflow and Mario can replicate it.

## Core idea

Do not frame this as “using AI” or “asking ChatGPT.” Frame it as a repeatable commercial execution system:

> Context → Diagnosis → Angle → Message → Demo → Proposal → Client agent

The point is to turn messy conversations into commercial assets and next steps.

## Workflow Chris can teach Mario

1. **Receive real context**
   - prospect profile
   - WhatsApp/Telegram/Instagram conversation
   - objection
   - rough offer idea
   - client notes or voice note
   - proposal draft

2. **Diagnose quickly**
   - Who is the person/business?
   - What do they sell?
   - Where are they losing time?
   - Where are they losing sales?
   - What repeated conversations or knowledge should be captured?
   - Which BEAT stage is missing: trust, need, help, or urgency?

3. **Define the sales angle**
   - Do not sell “a chatbot.”
   - Sell a personalized AI copilot trained on the prospect’s business, tone, offers, objections, FAQs, and processes.
   - Lead with outcomes: save time, improve response quality, create follow-ups/proposals/content faster, and convert conversations into opportunities.

4. **Create a personalized mini demo**
   Use 3 cases based on the prospect’s business:
   - response to a real lead
   - follow-up for a stalled conversation
   - content/proposal/objection handling example

5. **Convert every conversation into an asset**
   - lead → message
   - objection → response
   - client → proposal
   - client info → configured agent package
   - idea → offer/demo/content
   - conversation → next steps

```text

Se trata de traerle contexto real: un lead, una conversación, una objeción, una idea, un cliente o una oportunidad.

El workflow es:
1. Le pasamos el contexto.
2. El agente detecta el ángulo comercial.
3. Nos da posibles dolores y oportunidades.
4. Nos escribe el mensaje o follow-up.
5. Si hay interés, armamos una mini demo.
6. Si avanza, convertimos la info del cliente en un agente listo para configurar.

Tú traes la experiencia, la intuición comercial y el contexto.
El agente ayuda a ordenarlo, escribirlo y convertirlo en siguiente paso.

En resumen:
lead → mensaje
objeción → respuesta
cliente → propuesta
info → agente
idea → demo
conversación → acción
```
