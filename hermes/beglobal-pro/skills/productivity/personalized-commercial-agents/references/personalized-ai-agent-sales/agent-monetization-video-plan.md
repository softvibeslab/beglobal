# Agent monetization video plan

Use this reference when the user wants to turn the personalized AI agent business plan into a short sales/education video.

## Default video format

- Platform: Reels / TikTok / Shorts
- Length: 45–60 seconds
- Orientation: vertical 9:16
- Style: clear, commercial, practical; avoid generic AI hype
- Structure: hook → problem → model → offer ladder → CTA

## Core angle

> “Cómo monetizar agentes de IA personalizados: de una demo a un negocio recurrente.”

## Suggested script beats

1. **Hook**
   - “La oportunidad no es vender chatbots. Es vender agentes personalizados que resuelven problemas reales de negocio.”

2. **Problem**
   - “Muchos negocios pierden tiempo respondiendo lo mismo, dando seguimiento tarde, creando contenido sin sistema o capacitando equipos de forma inconsistente.”

3. **Solution**
   - “Un agente entrenado con la marca, servicios, objeciones, tono y procesos del cliente puede ayudar a vender mejor, responder más rápido y ejecutar con más consistencia.”

4. **Business model**
   - “Primero haces una mini entrevista. Después preparas una demo personalizada en 3 a 5 días. Si le hace sentido al cliente, vendes setup inicial más mensualidad.”

5. **Offer ladder**
   - “Puedes empezar con un agente comercial, subir a copiloto completo y después agregar automatizaciones, herramientas, capacitación o soporte premium.”

6. **CTA**
   - “Si quieres monetizar agentes de IA, empieza con una demo concreta para un nicho concreto. No vendas tecnología; vende resultado.”

## Visual plan

- Scene 1: bold title: “No vendas chatbots”
- Scene 2: pain bullets: DMs, follow-ups, contenido, capacitación
- Scene 3: diagram: cliente → entrevista → demo → setup → mensualidad
- Scene 4: offer ladder: demo / agente comercial / copiloto premium
- Scene 5: CTA: “demo personalizada + resultado claro”

## Production workflow with Hermes tools

If native video generation is unavailable, build the asset manually:

1. Draft short script.
2. Generate TTS voiceover.
3. Create simple vertical slide visuals or AI background images.
4. Add subtitles and basic motion with ffmpeg.
5. Export MP4 vertical for social.

## Positioning reminder

Keep the message aligned with the sales skill: this is not “automation” first and not “chatbot” first. Lead with monetization, sales consistency, time saved, response speed, and personalized business context.
