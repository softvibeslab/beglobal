# Product Reels para ecommerce / paca / calzado

Usa esta referencia cuando el alumno pida crear, mejorar o revisar videos cortos para vender productos en redes.

## Principio

Para vender productos físicos en Reels/TikTok, el video debe sentirse como anuncio de producto, no como diapositiva. La prioridad es: producto visible, texto mínimo, movimiento, confianza y CTA a DM.

## Diagnóstico antes de crear

1. ¿El producto es nuevo, segunda mano o paca?
2. ¿Qué objetivo tiene el video: mensajes, visitas, catálogo, confianza o cierre?
3. ¿Qué estilo quiere: comercial/colorido, limpio catálogo, premium/deportivo/editorial?
4. ¿Hay fotos reales suficientes: frente, lateral, suela, detalles/desgaste?

## Reglas visuales

- Usar fotos reales del producto, especialmente si es segunda mano.
- Evitar imágenes generadas con IA como foto principal del producto real.
- Texto grande, máximo 2 líneas por escena.
- No saturar con precio, tallas, envío y CTA en todas las escenas.
- Mostrar detalles reales: suela, costados, punta, desgaste y estado.
- Para producto usado: incluir “fotos reales” o “segunda mano en buen estado” para reducir reclamos.
- Verificar encuadre con una hoja de contacto/contact sheet antes de entregar.

## Estilos recomendados

### Comercial/colorido
Bueno para Facebook Marketplace, historias y ventas rápidas.
- Colores vivos de la marca.
- CTA directo: “Manda tu talla”.
- Precio visible.
- Ritmo rápido.

### Catálogo limpio
Bueno para Mercado Libre o catálogo por WhatsApp.
- Fondo claro.
- Producto centrado.
- Textos informativos cortos.
- Menos efectos.

### Premium/deportivo/editorial
Cuando el usuario pida “tipo Nike”, “tipo Adidas”, “más profesional”, “campaña”.
- No usar logos, nombres ni elementos registrables de marcas externas.
- Inspirarse solo en códigos visuales: fondo oscuro, tipografía bold, contraste fuerte, movimiento diagonal, textura/grano, beat energético.
- Menos copy; más impacto visual.
- Usar palabras tipo campaña: “BLACK SHOES”, “REAL DETAILS”, “CASUAL / FORMAL”, “DM: TALLA”.
- Evitar colores demasiado comerciales o botones tipo app si se busca premium.

## Storyboard base 10–12 segundos

1. Hook: producto completo + frase fuerte.
   - “ZAPATOS NEGROS” / “BLACK SHOES”
2. Uso o estilo.
   - “CASUAL / FORMAL”
3. Confianza.
   - “REAL DETAILS” / “FOTOS REALES”
4. Disponibilidad/precio.
   - “TALLAS 6–11” / “$1,000 MXN”
5. CTA.
   - “DM: TALLA”

## Pitfalls detectados

- Avatar hablando puede verse genérico y distraer del producto; úsalo solo si el usuario lo pide explícitamente.
- Collages con demasiada información parecen diapositivas, no video.
- Si cada foto no tiene zoom/paneo/fondo animado/transición, el usuario puede percibirlo como imagen estática.
- Las líneas decorativas fuertes pueden tapar texto o producto; mantenerlas sutiles.
- El CTA debe caber completo en pantalla; revisar que no se corte en la contact sheet.

## Entrega sugerida

Al entregar el video, incluir:
- Archivo del video.
- Caption corto listo para publicar.
- Portada recomendada.
- Siguiente acción clara: publicar, probar historia/reel o mandar captura de métricas/mensajes.
