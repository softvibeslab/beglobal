# Agentic Lab — Shopify landing para agentes personalizados

Usa esta referencia cuando Chris/Roger/equipo pidan crear una tienda/landing para vender agentes agénticos personalizados bajo una marca independiente de Be Global.

## Decisiones base de la oferta

- Marca pública: **Agentic Lab**.
- No usar **Be Global** como nombre comercial de esta oferta.
- Producto: agentes de IA personalizados para empresas.
- Modelo: servicio premium bajo diagnóstico; evitar precios fijos públicos si el usuario elige diagnóstico.
- CTA principal: **Agendar diagnóstico**.
- Canal inicial de cierre: WhatsApp.
- Link acordado: `https://wa.me/529841457476?text=Hola%2C%20quiero%20agendar%20un%20diagn%C3%B3stico%20para%20crear%20un%20agente%20de%20IA%20personalizado%20para%20mi%20empresa.`
- Plataforma recomendada para presupuesto moderado: Shopify básico, sin PageFly/Gempages al inicio.
- Dominio ideal elegido: `agenticlab.ai`.
- Estilo elegido: azul marino + cian, premium tecnológico/corporativo.

## Diagnóstico conversacional recomendado

Si el usuario no sabe la plataforma o estructura, guiar con decisiones pequeñas:

1. Plataforma: Shopify básico vs landing rápida vs builder.
2. Modelo comercial: precios visibles vs bajo diagnóstico.
3. CTA: Agendar diagnóstico vs cotizar agente.
4. Canal: WhatsApp vs formulario vs llamada.
5. Identidad visual: paleta y sensación de marca.

Dar máximo 1–3 decisiones por mensaje. Si el usuario responde con una letra, confirmar la decisión y avanzar al siguiente bloque.

## Copy base de landing Shopify

### Hero

**Agentes de IA diseñados para operar dentro de tu negocio**

Creamos agentes inteligentes personalizados para empresas que necesitan vender mejor, atender más rápido, dar seguimiento y entrenar equipos con su propio conocimiento.

CTA: **Agendar diagnóstico**

Microcopy: *Cada proyecto se diseña bajo diagnóstico según tus procesos, canales y objetivos.*

### Problema

**Tu operación no debería depender de respuestas manuales todo el tiempo**

Cuando los prospectos no reciben respuesta rápida, las oportunidades se enfrían. Cuando el seguimiento depende de memoria o tiempo disponible, se pierden ventas. Cuando cada persona explica distinto, la experiencia del cliente se vuelve inconsistente.

### Solución

**No vendemos bots genéricos. Diseñamos agentes a la medida.**

Cada agente se entrena con información real de la empresa: oferta, preguntas frecuentes, objeciones, procesos, tono de marca, scripts, catálogos, manuales o materiales internos.

Bullets:
- Atienden prospectos y clientes.
- Responden preguntas frecuentes.
- Califican oportunidades.
- Dan seguimiento.
- Apoyan ventas.
- Entrenan equipos.
- Ordenan procesos repetitivos.

### Soluciones

- **Ventas:** explican la oferta, responden objeciones, califican prospectos y apoyan el proceso comercial.
- **Atención al cliente:** responden dudas frecuentes, horarios, servicios, políticas y solicitudes comunes.
- **Ecommerce:** catálogo, recomendaciones, seguimiento de pedidos, ofertas, recuperación y soporte.
- **Capacitación interna:** entrenados con manuales, scripts, procesos y mejores prácticas.

### Cómo funciona

1. Diagnóstico.
2. Diseño.
3. Entrenamiento.
4. Implementación.
5. Optimización.

### Planes bajo diagnóstico

Mostrar tarjetas orientativas sin precio público:

- **Starter:** primer agente funcional; FAQs, captura de leads, atención básica, seguimiento inicial.
- **Pro:** ventas/atención/ecommerce activo; seguimiento comercial, CRM básico, catálogo, atención multicanal.
- **Enterprise:** varios procesos/áreas; varios agentes, capacitación interna, integraciones, panel y optimización continua.

Todas las tarjetas: **Cotización bajo diagnóstico** + botón **Agendar diagnóstico**.

### Información para entrenar

Sitio web, catálogo, FAQs, scripts de venta, audios, PDFs, manuales internos, procesos comerciales, conversaciones ejemplo y objeciones comunes.

### CTA final

**¿Listo para diseñar tu agente de IA?**

Agenda un diagnóstico por WhatsApp y revisamos qué proceso de tu empresa puede convertirse en un agente inteligente personalizado.
