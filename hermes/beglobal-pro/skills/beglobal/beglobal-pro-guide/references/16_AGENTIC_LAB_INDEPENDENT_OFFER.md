# Agentic Lab / oferta independiente de agentes personalizados

Usa esta referencia cuando Chris/Roger/equipo estén construyendo una tienda/landing para vender agentes agénticos personalizados como oferta comercial separada de Be Global.

## Corrección clave del usuario

- No usar **Be Global** como nombre visible de esta oferta.
- Be Global puede quedar como operación interna/equipo, pero la marca comercial debe ser independiente.
- Si el usuario corrige el naming, confirma y cambia inmediatamente el marco sin insistir en Be Global Smart Agent.

## Marca elegida en esta sesión

**Agentic Lab**

Posicionamiento base:

> Laboratorio de agentes inteligentes personalizados para empresas.

Promesa:

> Creamos agentes de IA entrenados con la información, procesos y estilo de tu negocio para ayudarte a vender, atender clientes, dar seguimiento a leads y capacitar equipos.

## Arquitectura de oferta

La tienda debe organizarse por soluciones, no por “todo para todos”. Líneas principales:

1. Ventas
2. Atención al cliente
3. Seguimiento de leads
4. Ecommerce
5. Capacitación interna
6. Operación/soporte administrativo cuando aplique

## Modelo comercial preferido

El usuario exploró dos rutas:

- Implementación + mensualidad con precios “desde”.
- Todo bajo diagnóstico.

La ruta que pidió ver al final fue **todo bajo diagnóstico**:

- No mostrar precios cerrados.
- No mostrar paquetes como productos rígidos.
- Sí se pueden mostrar niveles orientativos tipo Starter / Pro / Enterprise, pero todos con texto: **Cotización bajo diagnóstico**.

## CTA elegido

CTA principal:

> Agendar diagnóstico

Canal elegido para el diagnóstico inicial:

> WhatsApp

CTA final recomendado:

> Agendar diagnóstico por WhatsApp

Mensaje prellenado sugerido:

> Hola, quiero agendar un diagnóstico para crear un agente de IA personalizado para mi empresa.

## Copy base para landing

Título:

> Agentes de IA diseñados para operar dentro de tu negocio

Texto:

> Agentic Lab crea agentes inteligentes personalizados para empresas que necesitan vender mejor, atender más rápido, dar seguimiento y entrenar equipos con su propio conocimiento.
>
> Cada agente se diseña bajo diagnóstico, porque cada empresa tiene procesos, clientes, objeciones y necesidades diferentes.

Mensaje clave:

> No vendemos bots genéricos. Diseñamos agentes inteligentes a la medida de tu empresa.

## Flujo de venta por WhatsApp

1. La persona entra a la landing.
2. Entiende qué hace Agentic Lab.
3. Da clic en **Agendar diagnóstico por WhatsApp**.
4. WhatsApp abre con mensaje prellenado.
5. Se hacen 5–6 preguntas rápidas.
6. Si califica, se agenda llamada.
7. Después de la llamada, se manda propuesta personalizada.

Preguntas sugeridas:

1. ¿Cuál es el nombre de tu empresa y giro?
2. ¿Qué proceso quieres mejorar con IA? ventas, atención, seguimiento, ecommerce, capacitación u otro.
3. ¿Dónde atiendes hoy a tus prospectos/clientes? WhatsApp, Instagram, Facebook, web, CRM u otro.
4. ¿Ya tienes información para entrenar al agente? scripts, catálogo, FAQs, audios, PDFs o manuales.
5. ¿Qué resultado esperas lograr con el agente?

## Pitfalls

- No decir “Be Global Smart Agent” si el usuario aclaró que esta oferta no usará Be Global.
- No encasillar el servicio como tienda ecommerce tradicional; es landing de servicio premium personalizado.
- Si el usuario dice “todos” como público, no comunicar “para todos”; organizar por soluciones y casos de uso.
- Evitar promesas de ventas garantizadas. Hablar de sistema, atención, seguimiento, consistencia y operación.
