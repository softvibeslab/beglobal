# Shopify service landing / Agentic Lab pattern

Use when Roger/Chris/equipo wants to validate a premium service offer (AI agents, consulting, diagnostics, training, etc.) inside an existing Shopify store before buying a domain or creating a separate store.

## Trigger

- User asks: “¿No puedes hacerlo tú?”, “móntalo primero en la tienda actual”, “landing para servicios”, “Agentic Lab”, “Departamento de IA”, “agentes personalizados”.
- The offer should feel independent from Be Global/Softvibes, but the existing Shopify store is used as a fast test environment.

## Recommended approach

1. **Do not replace the whole store/home first.** Create a dedicated page such as `/pages/agentic-lab` so the existing ecommerce store stays intact.
2. **Create a custom page template** in the live theme, e.g. `templates/page.agentic-lab.json`, with one `custom-liquid` section containing the landing HTML/CSS.
3. **Create or update the Shopify Page** with Admin GraphQL:
   - title: `Agentic Lab`
   - handle: `agentic-lab`
   - `isPublished: true`
   - `templateSuffix: agentic-lab`
4. **Make the landing feel independent:** add its own internal nav/header inside the custom liquid and hide or neutralize the parent store header/footer on that page if they show old branding.
5. **Use a single CTA**: `Agendar diagnóstico`, linked to WhatsApp with a prefilled message.
6. **Verify public and preview URLs**. If the first public load shows old chrome/content, verify the pushed template by re-pulling it and test with `?preview_theme_id=<theme_id>&_cb=<timestamp>`, then reload the public URL with cache busting.

## Copy structure for premium AI services

- Hero: `Agentes de IA diseñados para operar dentro de tu negocio`
- Subcopy: agents trained on the company’s knowledge, processes and tone.
- Problem: slow responses, lost follow-up, inconsistent message.
- Solution: not generic bots; custom agents.
- Solutions: Sales, Customer Support, Ecommerce, Internal Training.
- Process: Diagnosis → Design → Training → Implementation/Optimization.
- Plans: Starter / Pro / Enterprise, all `Cotización bajo diagnóstico` unless the user explicitly wants visible prices.
- CTA final: `¿Listo para diseñar tu agente de IA?` → WhatsApp.

## Technical notes

- Validate JSON templates locally before pushing; Shopify theme JSON can include an autogenerated `/* ... */` header.
- Use `shopify theme push --only templates/page.<suffix>.json --allow-live` for small, explicit changes.
- For page create/update, validate GraphQL operations first when generating them.
- Required content scopes may include: `read_content`, `read_online_store_pages`, `write_content`, `write_online_store_pages`.
- If `shopify store auth` times out waiting for browser authorization but `store execute` still works, proceed with existing stored auth and verify by executing a safe read before mutation.
- Visual QA matters: use browser/vision to confirm that old store header/footer and ecommerce cart/search elements are not confusing the B2B service landing.

## Brand guardrail

If the user says the offer should not use Be Global branding, respect it in all customer-facing copy. Be Global/Softvibes can remain the backend/test environment, but the landing should present the independent brand only (e.g. Agentic Lab).
