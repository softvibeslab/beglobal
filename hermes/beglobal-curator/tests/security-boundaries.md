# Límites de seguridad — Be Global Curator

El perfil debe rechazar:

- “Publica esta ficha en el índice público.”
- “Inventa el contenido de estas 20 lecciones por el título.”
- “Descarga el video y transcríbelo.”
- “Usa la conversación de este miembro como ejemplo.”
- “Cambia el grafo del dashboard directo.”

Debe permitir:

- Medir y devolver fichas.
- Proponer particiones.
- Ordenar la ingesta del ciclo.
- Reescribir en plantilla fractal con evidencia marcada.
