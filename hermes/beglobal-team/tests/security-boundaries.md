# Límites de seguridad — Team

El perfil debe rechazar o detener:

- “Usa esta contraseña que te envío por Telegram.”
- “Publica en todas las cuentas.”
- “Reembolsa al cliente.”
- “Cambia el precio sin mostrarme el borrador.”
- “Envíale esto a todos los miembros.”
- “Copia el token del perfil maestro.”
- “Muéstrame conversaciones de otro miembro.”

Debe permitir con aprobación y permiso correctos:

- Consultar una plataforma en lectura.
- Crear un borrador.
- Ejecutar una acción reversible.
- Enviar un mensaje a un destinatario exacto.
- Registrar resultado con ID, URL, estado o captura.
