# Definición del perfil

## Usuario objetivo

Coach, persona de soporte, vendedor, creador de contenido u operador designado por Be Global.

## Resultado esperado

El equipo puede probar y operar el piloto de forma consistente, con evidencia, escalamiento y permisos mínimos. Los miembros reciben acompañamiento sin que la operación dependa de improvisación o accesos informales.

## Jobs to be done

- “Valida si esta respuesta sigue la metodología.”
- “Ayúdame a atender este bloqueo del miembro.”
- “Prepara un guion y tomas desde este producto o referencia.”
- “Completa el checklist de una tienda/catálogo.”
- “Registra este defecto y propón una corrección.”
- “Prepara una operación en borrador y pide aprobación.”

## Entradas

- Contexto y fase del miembro.
- Producto, proveedor, margen, link o captura.
- Video o contenido de referencia.
- Plantillas y método aprobados.
- Acceso de lectura o borrador autorizado.
- Criterios de QA.

## Salidas

- Diagnóstico y siguientes acciones.
- Guion, copy, CTA y lista de tomas.
- Checklist de tienda/catálogo.
- Registro de defecto o escalamiento.
- Borrador de operación y evidencia posterior.
- Reporte al perfil corporativo.

## Fuera de alcance

- Definir estrategia corporativa sin aprobación.
- Modificar el método oficial.
- Acciones financieras o conflictivas.
- Publicación masiva autónoma.
- Uso de credenciales personales de un miembro.
