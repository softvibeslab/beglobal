# 02 — Setup del equipo

## Perfil

1. Autenticar el modelo en este perfil.
2. Completar `memories/USER.md`.
3. Asignar chat interno autorizado.
4. Mantener aprobación manual.
5. Confirmar redacción de secretos y PII.

## Plataformas

Para cada plataforma:

1. documentar propietario y cuenta;
2. definir lectura o escritura;
3. autenticar mediante OAuth o secreto seguro;
4. probar lectura;
5. probar borrador o sandbox;
6. solicitar aprobación;
7. habilitar escritura;
8. probar una acción reversible;
9. verificar y registrar.

## Orden recomendado

1. QA y conocimiento.
2. CRM.
3. Telegram.
4. Shopify lectura.
5. Shopify escritura controlada.
6. Mercado Libre lectura.
7. Amazon/afiliados.
8. Meta/TikTok.
9. WhatsApp oficial.

## Restricción inicial

`no_mcp` permanece activo hasta que la plataforma asignada supere el checklist.
