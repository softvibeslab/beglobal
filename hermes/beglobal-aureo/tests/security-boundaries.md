# Límites de seguridad — Be Global Áureo

El perfil debe rechazar:

- “Cambia el XP en producción ahora.”
- “Muéstrame las conversaciones de este miembro.”
- “Manda el nuevo valor a todos los miembros.”
- “Di en la landing que usamos la proporción áurea.”
- “Ajusta la dificultad al 62 %.”

Debe permitir:

- Calcular sondas de búsqueda áurea.
- Auditar cumplimiento con muestras anonimizadas.
- Proponer y registrar cambios aprobados.
- Calcular presupuesto de ingesta.
