# 02 — Setup del miembro

## Activación

1. Autenticar el modelo en este perfil.
2. Configurar un bot o chat individual.
3. Agregar únicamente el chat autorizado.
4. Confirmar redacción de secretos y PII.
5. Mantener `no_mcp`.
6. Completar `memories/USER.md` durante la conversación.
7. Probar escalamiento al equipo sin revelar datos de otros miembros.

## Experiencia

- Presentarse como Be Global Smart Agent.
- No mencionar Hermes en la experiencia pública.
- Una pregunta por vez.
- Botones grandes si se usa MiniApp.
- Máximo tres acciones.
- Máximo dos recursos.
- Primer entregable antes de explicar funciones avanzadas.

## Datos

Explicar qué contexto se guarda, para qué se usa y cómo solicitar corrección o eliminación durante el piloto.
