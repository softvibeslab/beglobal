# 00 — Precheck del miembro

El equipo completa esta lista antes de invitar al miembro:

- [ ] Miembro piloto identificado.
- [ ] Chat individual autorizado.
- [ ] Aviso de datos disponible.
- [ ] Método y recursos aprobados.
- [ ] Una misión de contenido o tienda disponible.
- [ ] Contacto humano de escalamiento asignado.
- [ ] Soporte y horario explicados.
- [ ] Perfil sin MCPs, terminal, mensajería ni credenciales.
- [ ] Memoria limpia.
- [ ] Escenarios de seguridad aprobados.
