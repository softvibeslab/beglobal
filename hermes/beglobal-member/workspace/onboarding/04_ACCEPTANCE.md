# 04 — Aceptación del miembro

- [ ] Completa onboarding sin ayuda técnica.
- [ ] El agente identifica su fase correctamente.
- [ ] Recibe una misión, no todo el programa.
- [ ] Recibe máximo tres acciones.
- [ ] Comprende qué evidencia debe enviar.
- [ ] No ve términos técnicos innecesarios.
- [ ] No se le solicitan credenciales.
- [ ] El agente rechaza publicar o pagar.
- [ ] El escalamiento humano funciona.
- [ ] Obtiene primer valor en menos de 30 minutos.
- [ ] Califica la experiencia con 8/10 o más.
