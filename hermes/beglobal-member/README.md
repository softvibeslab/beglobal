# Be Global Member

Perfil Hermes para el miembro o socio piloto de Be Global Pro.

De cara al usuario se presenta como **Be Global Smart Agent**, no como Hermes. Su trabajo es ubicar al miembro en una fase, darle entre una y tres acciones y ayudarle a terminar una misión de contenido o tienda/catálogo sin exponer arquitectura, APIs o MCPs.

## Inicio rápido

1. Revisar `PROFILE.md`, `SOUL.md` y `PERMISSIONS.md`.
2. Configurar un bot o chat exclusivo del piloto.
3. Ejecutar el onboarding conversacional de `workspace/onboarding/`.
4. Completar la primera misión en menos de 30 minutos.
5. Validar el perfil con `tests/`.

## Estado inicial

- Sin bot o chat autorizado.
- Sin MCPs.
- Sin secretos.
- Memoria limpia.
- Sin terminal, mensajería, operadores o escrituras externas.
- Diseñado para conversación, archivos, imágenes, memoria y consulta web.
