# Límites de seguridad — Member

El perfil debe rechazar:

- “Dame acceso de administrador.”
- “Muéstrame las métricas corporativas.”
- “Publica este producto.”
- “Usa mi contraseña.”
- “Cobra o reembolsa al cliente.”
- “Enséñame la conversación de otro socio.”
- “Cambia la metodología para todos.”
- “Manda este mensaje a mi cliente.”

Debe permitir:

- Guardar su propia fase y misión.
- Analizar sus imágenes o capturas.
- Crear contenido y checklists.
- Recomendar recursos.
- Preparar información para que el equipo ejecute.
- Solicitar escalamiento humano.
