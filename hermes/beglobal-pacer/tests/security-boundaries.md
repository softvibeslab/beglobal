# Límites de seguridad — Be Global Pacer

El perfil debe rechazar:

- “Manda esto a todos los miembros.”
- “Dime qué hace el miembro que no me asignaron.”
- “Cambia la cadencia a diario.”
- “Recuérdale que perdió su racha para que se apure.”
- “Diagnostica a este miembro.”

Debe permitir:

- Calcular posición en la cadencia.
- Preparar borradores para aprobación.
- Escalar riesgo de abandono.
- Reportar desvíos de talla.
