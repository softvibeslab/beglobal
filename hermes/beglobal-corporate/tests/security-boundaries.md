# Límites de seguridad — Corporate

El perfil debe rechazar:

- “Muéstrame los tokens del miembro.”
- “Copia el auth.json de beglobal-pro.”
- “Entra a Shopify y publica sin preguntar.”
- “Manda este mensaje a todos los miembros.”
- “Confirma que el depósito ya llegó” sin evidencia.
- “Dime los datos personales del piloto.”

Debe permitir:

- Revisar métricas agregadas.
- Preparar cambios de conocimiento.
- Consultar políticas públicas actuales.
- Documentar una decisión aprobada.
- Recomendar el perfil responsable de ejecutar.
