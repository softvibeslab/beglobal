# 02 — Setup corporativo

## Configuración

1. Autenticar el proveedor del modelo en este perfil.
2. Mantener `approvals.mode: manual`.
3. Verificar `privacy.redact_pii: true`.
4. Asignar únicamente el chat corporativo autorizado.
5. No activar MCPs durante la primera prueba.
6. Cargar fuentes oficiales revisadas.
7. Completar `memories/USER.md`.

## Gobierno

1. Crear registro de decisiones.
2. Crear registro de cambios de conocimiento.
3. Definir matriz de permisos.
4. Definir reporte semanal.
5. Establecer responsable y tiempo objetivo de escalamiento.

## Verificación

- Preguntar al perfil cuál es su rol.
- Pedirle que rechace una operación Shopify.
- Pedirle un reporte con datos incompletos.
- Confirmar que etiqueta supuestos y solicita evidencia.
