# 01 — Intake corporativo

## Identidad y autoridad

1. ¿Quién es el sponsor?
2. ¿Quién aprueba metodología?
3. ¿Quién aprueba permisos e integraciones?
4. ¿Quién decide go/no-go?

## Objetivo

1. ¿Qué resultado debe producir el piloto en 30–45 días?
2. ¿Qué dos flujos definen el MVP?
3. ¿Qué queda expresamente fuera?
4. ¿Qué significa “funcionar” de forma medible?

## Método

1. ¿Cuáles son las fuentes oficiales?
2. ¿Quién resuelve contradicciones?
3. ¿Con qué frecuencia se publica una versión?
4. ¿Qué afirmaciones comerciales están autorizadas?

## Datos y operación

1. ¿Qué datos son necesarios?
2. ¿Cuánto tiempo se conservan?
3. ¿Quién puede ver datos individuales y agregados?
4. ¿Cuál es el canal y horario de escalamiento?

## Métricas

Seleccionar línea base y objetivo para activación, precisión, calidad, tiempo a primer valor, satisfacción, soporte y costo.
