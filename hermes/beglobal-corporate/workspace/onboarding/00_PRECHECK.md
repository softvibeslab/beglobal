# 00 — Precheck corporativo

Completar antes de configurar accesos.

- [ ] Sponsor nombrado.
- [ ] Propietario de producto nombrado.
- [ ] Participantes del piloto identificados.
- [ ] Canal inicial aprobado.
- [ ] Alcance y dos misiones del MVP aprobados.
- [ ] Promesa segura y exclusiones aprobadas.
- [ ] Responsable de datos y soporte identificado.
- [ ] Estado comercial documentado sin asumir pago.
- [ ] Fuentes oficiales reunidas.
- [ ] Política de credenciales aceptada: OAuth o gestor seguro, nunca chat.

Si falta sponsor, propietario de producto o política de datos, el setup queda bloqueado.
