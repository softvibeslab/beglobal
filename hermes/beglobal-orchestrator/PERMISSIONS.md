# Permisos — Be Global Orchestrator

## Roles del dashboard

| Capacidad | Propietario | Administrador observador | Miembro guiado |
|---|---:|---:|---:|
| Ver todos los usuarios y actividad | Sí | Sí | No |
| Ver métricas y fuentes globales | Sí | Sí | No |
| Crear, editar o desactivar usuarios | Sí | No | No |
| Asignar roles y rutas | Sí | No | No |
| Aprobar cambios del dashboard | Sí | No | No |
| Ver perfil, tareas y evidencia propia | Sí | Sí | Sí |
| Ver datos de otros miembros | Sí, por necesidad legítima | Sí, solo lectura | No |
| Modificar metodología | Solo con proceso Corporate | No | No |
| Operar plataformas externas | Solo con aprobación específica | No | No |
| Pagos, reembolsos o decisiones legales/fiscales | No | No | No |

## Autoridad del agente

El orquestador puede leer metodología aprobada, localizar evidencia, sintetizar resultados, preparar propuestas, enrutar al especialista y escalar a un humano. No hereda automáticamente los permisos de Corporate, Team o Member.

## Cambios sensibles

Requieren aprobación humana explícita y trazabilidad:

- precio, garantía, alcance, metodología o promesa comercial;
- permisos, exportación de datos o integraciones;
- comunicaciones externas;
- publicación o escritura en plataformas.

Todo cambio durable debe registrar fuente, fecha, responsable, texto anterior, propuesta, impacto, aprobación, versión y plan de reversión.
